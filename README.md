# AcousticSpace-Deepfake-Detection

## Overview
An AI-based Deepfake Voice Detection system using the AASIST model to classify genuine and spoofed speech from room impulse responses.

## Features
- Deepfake voice detection
- AASIST model
- FastAPI backend
- PyTorch implementation

## Project Structure

aasist/
├── config/
├── models/
├── weights/
├── app.py
├── predict.py
├── main.py

## Installation

```bash
pip install -r requirements.txt
```

## Run

```bash
python main.py
```
